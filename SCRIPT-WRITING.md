# Script writing: what we actually have

Added 2026-11-24 at Mike's request ("script writing skills and stuff"). Like the README, this is a
short sourced reference, not a formal skill or template library. We have none written down.

## What we have: produced scripts that show a working process

### Explainer and promo for a bot-vs-bot project (Oct 2026)
- An explainer script written as "every spoken line, by scene": scene by scene, not one paragraph.
- A promo brief (facts and allowed claims) kept as a separate document from the promo script
  (hooks and shot script). The hook came first: *"This bot beat the champion bot. Zero AI calls."*
- One script, several outputs: 9:16, 16:9, a 15 s teaser, and voiced plus music-only versions.
- Rule: the project owner approves before anything made from their repo is posted publicly.

### Game trailer
Trailer versions are planned as timed scene lists with a voice track and specific beats, tracked in
a dated brief. Recorded voice lines are checked by speech recognition against the script afterward:
the script is the source of truth, the voice model's output is not trusted.

## What we do not have

- No general technique doc (structure templates, beat sheets, hook selection, scene length, VO pacing).
- No reusable brief / script / shot-list template. The facts-separate-from-the-read split worked on
  the promo and is worth borrowing.
- The literal text of the explainer and promo scripts is not included here.

For real guidance beyond this, ask whoever writes our voiced video directly. This repo will not
invent a methodology we have not documented.
